# G3_POO
Este es nuestro trabajo para el curso de Programacion Orientada a Objetos

## Nombre y contexto del proyecto
Nuestro proyecto se titula: "Gestión de entrada y salida de productos para una bodega" y ha sido creado por:
- Armas Salinas, Gabriela
- Castro Marchena, Edison Marcel
- Rios Bernaola, Fabio Enrique
- Salvador Cabezas, Pedro Hugo

Actualmente, el control de la mercancía en tienda depende en gran medida de la memoria del personal y en anotaciones en una libreta o en hojas de calculo desactualizadas. Al no existir un sistema que registre en tiempo real, se produce un desfase constantr entre el inventario físico y datos registrados.
Nuestro código busca facilitar el control de inventario, diseñado específicamente para optimizar la logística en bodegas. Su objetivo central es agilizar el registro de entradas y salidas de mercancía, minimizando errores manuales y garantizando una administración de tienda eficiente, precisa y con datos actualizados.
